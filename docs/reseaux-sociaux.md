# Ouverture des comptes LinkedIn, Facebook et Instagram

Dossier de création des comptes PixForge : textes prêts à coller, visuels aux bonnes
dimensions, et ordre des opérations.

Les trois plateformes imposent que l'inscription soit faite par une personne, depuis
son propre compte, avec vérification par e-mail ou SMS. Ces étapes-là ne sont pas
délégables : tout le reste est préparé ici.

---

| Élément | Pourquoi | Statut |

| Numéro WhatsApp | Contact public, vérification Facebook et Instagram | `+261 32 48 616 95` |

> du site (`contact@…`) ne devient nécessaire que pour le badge de vérification
> LinkedIn, qui s'ajoute plus tard sans refaire la page.

## 2. Choisir le nom d'utilisateur, une fois pour les trois

Le même identifiant partout rend la marque reconnaissable et les liens prévisibles.
Par ordre de préférence, selon disponibilité :

1. `pixforge`
2. `pixforge.studio` (Instagram) / `pixforgestudio` (Facebook, LinkedIn)
3. `pixforge.dev`
4. `pixforge.mg`

**Vérifier la disponibilité sur Instagram en premier** : c'est la plateforme la plus
saturée. Le nom retenu là-bas devient le nom partout ailleurs, même s'il était libre
sous une autre forme.

---

## 3. Ordre de création

1. **Instagram** — réserve le nom d'utilisateur.
2. **Facebook** — la Page doit exister avant de relier Instagram en compte professionnel.
3. **Instagram, suite** — passer en compte professionnel et le relier à la Page Facebook
   (Paramètres → Type de compte et outils → Basculer en compte professionnel, puis
   Centre de comptes pour la liaison).
4. **LinkedIn** — page entreprise, depuis le profil personnel :
   *Pour les entreprises → Créer une page LinkedIn*.

### Coordonnées : où les saisir

L'adresse et le numéro ne se renseignent pas au même endroit selon la plateforme.

| Plateforme | Où | Quoi |
| --- | --- | --- |
| LinkedIn | Pas de champ e-mail public sur une page : l'adresse figure dans « À propos » | Site web dans le champ dédié |

## 5. Quel visuel pour quel champ

Tous les fichiers sont dans `public/brand/` et `public/brand/social/`.

| Plateforme | Champ | Fichier |
| --- | --- | --- |
| Les trois | Photo de profil | `brand/pixforge-avatar-1024.png` |
| LinkedIn | Image de couverture (4200×700) | `brand/social/linkedin-couverture-4200x700.png` |
| Facebook | Photo de couverture (851×315, fournie en 1702×630) | `brand/social/facebook-couverture-1702x630.png` |
| Instagram | Pas de couverture | — |

La photo de profil est recadrée en cercle par les trois plateformes : le monogramme
est centré avec la marge nécessaire, rien ne sera coupé.

Sur Facebook, la photo de profil recouvre un coin de la couverture et le mobile
recadre les bords : tout le texte de la bannière est donc regroupé au centre.

## 6. Brancher les comptes sur le site

Le fichier `.env` à la racine du projet contient déjà les coordonnées :

```dotenv
VITE_CONTACT_EMAIL=pixforgeweb@gmail.com
VITE_WHATSAPP_NUMBER=+261 32 48 616 95
```

Une fois les comptes créés, y ajouter leurs URL :

```dotenv
VITE_LINKEDIN_URL=https://www.linkedin.com/company/…
VITE_FACEBOOK_URL=https://www.facebook.com/…
VITE_INSTAGRAM_URL=https://www.instagram.com/…
```

Puis relancer `npm run build`. Les icônes apparaissent automatiquement dans le pied
de page ; une variable laissée vide masque simplement son icône.

> `.env` est ignoré par git : il n'est pas poussé avec le code. Sur Netlify, les
> mêmes variables doivent être saisies dans *Site configuration → Environment
> variables*, sinon le site déployé n'affiche aucune coordonnée.

Penser aussi à ajouter l'adresse du site dans chaque profil : le lien réciproque
renforce le référencement.

## 7. Premières publications

Cinq publications suffisent à ne pas laisser un compte vide, et tout le matériel
existe déjà dans le dépôt (`src/data/Projet/`).

1. **Présentation du studio** — qui vous êtes, ce que vous faites, pour qui.
   Visuel : la bannière de couverture.
2. **PixClinic** — gestion de clinique : rendez-vous, dossiers patients, facturation.
   Visuel : `pixclinic_01_tableau_de_bord.png`.
3. **PixGestion** — caisse, stock, ventes, devis et factures.
   Visuel : `pixgestion_tableau_de_bord_seul.png`.
4. **PixRH** — personnel, contrats, congés, préparation de la paie.
   Visuel : `pixrh_01_tableau_de_bord.png`.
5. **Notre méthode en 4 étapes** — échange, devis, développement, livraison.
   Reprendre le contenu de la section « Méthode » du site.

Ne rien publier qui ne soit vérifiable : pas de nombre de clients, pas d'années
d'expérience, pas de logo de client sans son accord écrit.

## 8. Régénérer les visuels

```bash
node scripts/generate-logo.cjs public/brand          # logos et avatars
python scripts/generate-social.py public/brand/social # bannières
```

Les dimensions des bannières sont des paramètres des fonctions `cover_linkedin` et
`cover_facebook` : la mise en page se recalcule à l'échelle. Utile le jour où une
plateforme change ses specs — c'est arrivé à LinkedIn, dont la couverture est passée
de 1128×191 à 4200×700.
